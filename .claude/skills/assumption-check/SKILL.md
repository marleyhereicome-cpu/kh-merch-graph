# assumption-check

`docs/assumptions.md` にまとめた各前提（KH4の発表・発売状況、Fortnite等の大型コラボ、Reddit解除、
Mercari Global App、競合の有無）を、公開情報を調べて再確認し、「現状の理解」「最終確認日」を更新するスキル。

## 手順

1. **`docs/assumptions.md` を読む**
   - 各前提の「なぜ重要か」「現状の理解」「確認方法」を確認する。指定がなければ全項目を対象にする。
   - 特定の前提だけ確認するよう頼まれた場合はそれだけを対象にしてよい。

2. **各前提を「確認方法」に沿って調べる**
   - Web検索・該当する公式サイト（スクウェア・エニックス公式、Fortnite公式、対象サブレディットのルール、
     メルカリ公式発表等）を実際に確認する。
   - 確認できた場合：一次情報のURLと、そこに書かれていた具体的な内容をメモする。
   - 確認できなかった場合（情報が無い・変化なし・アクセスできない）：その旨を正直に書く。
     「変化なし」を推測で断定しない。

3. **`docs/assumptions.md` を更新する**
   - 各前提の「現状の理解」を、調べた内容に基づいて書き換える（未確認のまま変える必要はない）。
   - 「最終確認日」を今日の日付に更新する。
   - 出典URLを本文中に追記する（「確認方法」の下、または「現状の理解」の文中に）。
   - 前提の内容自体（なぜ重要か）は基本的に変更しない。状況が大きく変わり前提そのものが
     成立しなくなった場合のみ、その旨を明記した上で書き換える。

4. **重要な変化があれば強調する**
   - 前提が覆った場合（例：KH4が正式発表された、Fortniteコラボが実施された等）は、
     このプロジェクトの計画（`docs/demand_baseline.md` や README 等）に影響する可能性が高いため、
     チャット上で目立つように報告する。「特に大きな変化はなかった」場合もそう明記する。

5. **報告する**
   - 前提ごとに「変化あり／なし」を一覧で示し、変化があったものは影響（次に何をすべきか）を一言添える。
