# 用語集（このプロジェクトで出てくる順）

- **MCP（Model Context Protocol）**：AIが外部の道具（ツール）を呼ぶための共通規格。私たちは「道具を差し出す側（サーバー）」を作る。
- **MCPサーバー**：ツールをまとめて提供するプログラム。「resolve_listing」などのツール名と入出力を宣言し、呼ばれたら答えを返す。
- **ツール（tool）**：AIが呼べる1つの機能。関数のようなもの。
- **stdio**：自分のPCの中でAIアプリ（Claude Desktop）とサーバーが直接会話する方式。公開せずに試すときに使う。
- **Streamable HTTP**：インターネット越しにMCPサーバーを呼ぶ方式。公開時に使う。
- **Node.js / TypeScript**：サーバーを書くための実行環境と言語。TypeScriptはJavaScriptに型（データの種類の宣言）を足したもの。
- **npm**：Node.jsの部品（パッケージ）を入れる道具。`npm install` で部品を取り込む。
- **リポジトリ（repo）**：プロジェクトのファイル一式とその変更履歴。Gitで管理し、GitHubに置く。
- **コミット（commit）**：変更を履歴として記録すること。「セーブポイント」。
- **CSV**：カンマ区切りの表。Excelやスプレッドシートで開ける。このプロジェクトのデータの正本。
- **JSON**：プログラムが読みやすいデータ形式。CSVから変換して使う。
- **SKU**：商品を一意に識別する単位。「一番くじKH第2弾 A賞 ソラ フィギュア」のように、これ以上分けなくてよい粒度。
- **商品ライン（product line）**：SKUの親。「一番くじKH第2弾」「Play Arts Kai」など。
- **名寄せ（entity resolution）**：ばらばらな表記（出品タイトル）を正規のSKUに結びつけること。このプロジェクトの技術的な心臓部。
- **状態語**：出品でよく使う「開封済」「箱なし」「難あり」などの語。
- **BYOL（Bring Your Own Listing）**：出品データを自分で取りに行かず、呼び出す側のAIが持ってきたテキストを解釈する設計。スクレイピング不要。
- **評価セット（eval set）**：正解付きのテスト問題集。名寄せが何点取れるかを測る。
- **信頼度（confidence）**：候補がどれくらい確からしいか（0〜1）。
- **Cloudflare Workers**：プログラムをインターネット上で動かす無料枠のあるサービス。公開版の置き場所。
- **KV**：Cloudflareの簡単な保存領域。修正報告や利用ログを置く。
- **レート制限**：同じ相手からの呼び出し回数を制限する仕組み。無料公開のため必要。
- **RAT（最大リスク仮説）**：これが外れたら事業が成立しない、という仮説。最初に検証する。
- **入手経路（acquisition_type）**：その商品がどうやって手に入るものか（通常の小売／一番くじ／プライズ／ガチャポン／ブラインド／購入特典など）。定価があるかどうかや、中古でしか手に入らないかどうかに直結する。
- **流入元タグ（src）**：Web版チェッカーのURLに `?src=reddit` のように付ける計測用の目印。サーバーには `src` と日時だけを記録し、個人を特定する情報は残さない。
- **カバレッジ（coverage）**：出品タイトルに対してカタログが「候補を出せる割合」。名寄せの正解率（`npm run eval`）とは別に、「そもそもカタログに載っていない商品がどれだけあるか」を見る指標（`npm run coverage`）。
- **前提（assumption）**：まだ確認できていないが、計画の前提にしている仮定（例：次回作の発表状況）。定期的に見直す（`docs/assumptions.md`）。
