# 作品ごとのデザイン（デザインシート）— 2026-11-12〜

作品ページは共通のテンプレート（`templates/ip/`）から作るが、**見た目の雰囲気は作品ごとに決める**。
王冠型のカードと「カードの棚」は Kingdom Hearts のために作ったもので、ほかの作品には使わない（KH だからこそ意味のある形のため）。

そのため、作品を公開する前に **デザインシート `ip-config/<ip>/design.json`** を作り、Marley の承認を受ける。

## 流れ（作品を選んだ段階から並行して進める）
1. **作品を選ぶ**：司令塔／Marley が次の作品を決める。カタログ発掘（データ）と同時に、UI/UX セッションがデザインの検討を始める。
2. **案を出す（UI/UX セッション）**：下の「決めること」を、無理のない範囲で 2 案ほど出す。
   - 各案に、カードとファーストビューの見た目が分かる簡単な試作（HTML かスクリーンショット）を添える。
   - 権利面の注意（下の「守ること」）を案ごとに書く。
3. **選ぶ（Marley）**：案を選ぶ／直す。決まったら `design.json` の `status` を `approved` にし、`approved_on` に日付を入れる。
4. **作る（コードセッション）**：決まった内容を実装する。
   - カードの形：テンプレートに `.card.<名前>` の CSS と `renderCard` の分岐を足し、`design.json` の `cardStyle` に書く。
   - ファーストビューの演出（棚のようなもの）：`ip-config/<ip>/shelf.html` などの差し込み部品で足す。
5. **公開する**：`data/ips.csv` の status を live にする。
   - **2026-11-12 より後に公開する作品は、`design.json` が `approved` でないとビルドが止まる**（`scripts/lib/ip-pages.mjs` の `validateIpConfig`）。
   - それ以前に公開した鬼滅の刃・ONE PIECE は、デザインが決まるまで `draft`（既定の `plain` カード）のまま出しておける。

## 決めること（design.json の項目）
| 項目 | 内容 | 例（KH） |
|---|---|---|
| `status` | `draft`（検討中）／`approved`（Marley 承認済み） | approved |
| `approved_on` | 承認した日 | 2026-11-08 |
| `cardStyle` | 一覧のカードの形。いまあるのは `plain`（既定）と `crown`（KH 専用） | crown |
| `motif` | 作品の何に着想を得るか（作中の象徴的なアイテムなど）。ロゴや紋章そのものは使わない | 作中のカード |
| `hero` | ファーストビューの演出。`none` なら共通の検索ヒーロー | card-shelf |
| `palette` | 色（舞台・文字・値札など） | 紺・生成り・クラフト |
| `texture` | 質感（紙・和紙・木・羊皮紙など） | 紙の粒子 |
| `watermark` | 背景の透かし（使う場合は、公式ロゴの使用可否を Marley が別途確認する） | KH ロゴ（作品ロゴのみ） |
| `music` | 音楽ボタンの曲（任意） | KH の楽曲 |
| `legal_notes` | 権利面で避けること | — |
| `docs` | 検討メモの場所 | — |

## 守ること
- 公式ロゴ・紋章・キービジュアル・キャラクターの絵を、デザインの部品として使わない（透かしのロゴは、Marley が個別に確認した場合だけ）。
- 作中のアイテムに「着想を得る」のはよいが、形・配色・レイアウトを写さない。自前の図形として描き直す。
- 商品写真は無加工（切り抜き・合成・生成をしない）。カードの窓に長方形のまま収める。
- 動きは `prefers-reduced-motion` で止める。スマホで重くしない（ぼかしの多用を避ける）。

## 作品別メモ
### 鬼滅の刃（`kimetsu-no-yaiba`）— A案「大正の木札」を選定（2026-11-12）
- カード（`cardStyle: kifuda`）：縦長の木の札。上の角を落とし、ひもを通す穴、木目。写真は和紙色の窓。ひもの色は種類ごとの色。
- ファーストビュー（`web/rail-hero.js`、`data-skin="kifuda"`）：夜の紺色の中、梁から木札が下がって並び、正面の1枚が大きくなる。動かすと札がひもで揺れる。
- **文字のルール（Marley 指示）**：日本語風の飾り文字は使わない。読める大きさの文字は本物の日本語（商品名・価格・日付・種類）だけ。
- 注意：キャラクター固有の羽織の柄と配色の組み合わせ（例：緑と黒の市松）をそのまま使わない。

### ONE PIECE（`one-piece`）— A案「手配書」を選定（2026-11-12）
- カード（`cardStyle: wanted`）：古い紙・二重の枠・英語の WANTED（Rye フォント、この作品のページだけ読む）。発売時の定価を懸賞金のように大きく。
- ファーストビュー（`web/rail-hero.js`、`data-skin="wanted"`）：板壁に釘で留めた手配書が少しずつ傾いて並び、正面の1枚がまっすぐ大きくなる。
- 注意：作中の手配書のレイアウト（海軍のマーク、DEAD OR ALIVE の位置、写真枠の形など）を写さない。一般的な西部劇の手配書の様式にとどめる。

### 共通
- カードの形は作品専用（`scripts/lib/ip-pages.mjs` の `CARD_STYLE_OWNER`）。別の作品で使うとビルドが止まる。
- ファーストビューの商品は `ip-config/<ip>/shelf.json`（点数）から `scripts/build-shelf.mjs` が選ぶ。写真が読み込めない商品は、見ている側でも外す。
