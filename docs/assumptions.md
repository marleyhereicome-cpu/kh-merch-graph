# 前提（Assumptions）

このプロジェクトの計画は、いくつかの「まだ確認できていない前提」の上に立っている。
思い込みのまま進めないよう、ここに前提を明文化し、確認するたびに日付を更新する。
定期的な再確認は `.claude/skills/assumption-check` スキルで行う想定。

各前提の「現状の理解」は執筆時点（このファイルを作った日）でのメモであり、断定ではない。
`最終確認日` が古い前提は、outreach戦略や需要見積もりの前に必ず再確認すること。
