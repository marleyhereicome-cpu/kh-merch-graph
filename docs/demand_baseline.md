# 需要ベースライン（Demand Baseline）

## 目的
outreach（Reddit・Discord等での回答活動）を始める前後で「需要が本当に増えているか」を比較できるように、
定点観測する数値をここに記録する。`docs/outreach_log.csv`（個別のやり取りの記録）とは別に、
チャネル全体の規模感を追う。

## 反応種別 R0〜R5（`docs/outreach_log.csv` の「反応種別」列の定義）
| コード | 意味 |
|---|---|
| R0 | 反応なし（既読スルー・返信なし） |
| R1 | 短い謝辞・相槌のみ |
| R2 | フォロー質問が来た（関心はある） |
| R3 | ツール（Web版チェッカー等）のリンクをクリックした形跡がある |
| R4 | 好意的なフィードバック、または他の人へ共有された |
| R5 | 継続利用・繰り返しの質問（リピーター化） |
