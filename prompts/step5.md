# Step 5 — 名寄せ精度の測定

CLAUDE.md と docs/SPEC.md を読んでから始めてください。日本語で、1つずつ。

やること：
1. `scripts/eval.mjs`（または ts）を作る：`data/eval_listings.csv` の各行を resolve にかけ、top-1 正解率、信頼度≥0.8 に絞った正解率、`NONE` の正答率を出す。間違えた行の一覧（タイトル・期待・実際・信頼度）も出す。`npm run eval`。
2. 実行して結果を見せる。
3. 間違いの上位パターンを3つに分類し、辞書（aliases、condition_lexicon）の追加か normalize/resolve の修正か、どちらで直すべきかを提案する。私が選んだものだけ直す。
4. 合格基準（SPEC 4章）に達するまで 2〜3 を繰り返すが、このセッションでは最大3周まで。

終わったら、最終スコアと、変えたファイル一覧、次に私がやることを3行以内で。コミットも提案して。
