# Step 7 — 配布の準備（ディレクトリ登録・Web一枚・README）

CLAUDE.md を読んでから始めてください。日本語で、1つずつ。

やること：
1. GitHub 公開用の README.md（英語）を書く：何ができるか、3つの使用例、対応IP（今はKingdom Heartsのみ）、接続方法（URL）、データの出典方針、免責（真贋は注意フラグ・価格は目安）、修正報告の方法。
2. MCP の公開ディレクトリ／レジストリに登録するために必要な情報（名前・説明・アイコン不要・URL・カテゴリ）を一覧にして、登録先ごとにやることを示す。登録は私が自分で行う。
3. `web/index.html` 一枚：出品タイトルを貼ると resolve_listing の結果が読みやすく出るページ。公開版のURLを呼ぶ。デザインは最小限。Cloudflare Pages に置く手順を示す。
4. 利用ログを週次で集計する `scripts/weekly-report.mjs` を作る（呼び出し数、ユニーク数、上位SKU、仕向国）。RAT-1の合格ライン（週300呼び出し・再訪30%）に対する現状が一目で分かる形。

終わったら、変えたファイル一覧と、次に私がやること（Reddit・Discord・動画などの配布は私の仕事）を3行以内で。コミットも提案して。
