KH Merch Graph — Listing Checker

Paste a Japanese secondhand-listing title (Mercari, Yahoo! Auctions, Suruga-ya, Mandarake, …) for Kingdom Hearts merchandise and get the likely official SKU, condition notes, and caution flags. This calls a public MCP server — it does not look at the listing site itself; you paste the text you already have.

Catalog entries are checked by a human against a primary source (see each result's "source" link). When confidence is low, this tool does not guess — it labels the match as weak instead of presenting it as a candidate. This tool never scrapes marketplaces; it only reads the text you paste here.
